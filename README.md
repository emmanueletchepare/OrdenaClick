# OrdenaClick

OrdenaClick es una aplicación web de gestión para registrar y ordenar hechos económicos, Pagos, compromisos, vencimientos, Caja y relaciones operativas, conservando historia y preparando información útil para previsibilidad, reportes y futura contabilidad.

La regla de producto es:

> **Simplificar la interfaz, no empobrecer los datos.**

La prioridad actual es llegar a una **Beta usable, estable y segura**, cerrando circuitos reales de punta a punta antes de continuar con funciones futuras o refactors secundarios.
